# **App Name**: Wisuda Memories

## Core Features:

- Image Upload & Display: Allow users to upload wisuda (graduation) photos and display them in a gallery.
- Package Information: Clearly present the different photography packages with their respective prices and features as described by the client, including direct WhatsApp links for booking.
- Contact Form with WhatsApp Integration: Implement a contact form with a direct link to WhatsApp (0812-XXXX-XXXX) for easy communication.
- AI-Powered Photo Enhancement: Use an AI tool to automatically enhance the quality (adjusting brightness, contrast, sharpness) of uploaded photos to ensure the best presentation.
- Client Testimonials: Showcase testimonials from previous clients to build trust and credibility.

## Style Guidelines:

- Primary color: Muted charcoal (#333333), evoking the professional feel described by the user.
- Background color: Light gray (#F0F0F0), providing a neutral backdrop to make the photos stand out.
- Accent color: Soft gold (#B4975A), as it is analogous to the primary hue but offers a rich, luxurious counterpoint. It is lower in brightness and higher in saturation than the primary.
- Headline font: 'Belleza', sans-serif, aligning to design, paired with 'Alegreya', serif, for body text, in blocks longer than a paragraph.
- Clean and modern layout with clear sections for Hero, About Us, Portfolio, Packages, and Contact.
- Minimalist icons to represent package features and contact information.
- Subtle fade-in animations on image load and scrolling to enhance user experience.
